Frequent Issues and Solutions

These are the most common operational issues and the quickest recommended next steps.

I cannot log in

Check that your username and password are correct. If you recently requested clinician access, your account may still be awaiting approval.

I can log in but cannot open the dashboard

Make sure you are opening the correct workspace for your role. Admin users should open the admin page and clinicians should open the clinician page.

Patient selection is not working

Refresh the page and confirm the backend is running. If the problem continues, contact support and provide the affected patient ID.

Assessment history is missing

Only assessments linked to the selected patient will appear. Try reselecting the patient and checking the latest assessment first.

I cannot export a PDF report

Make sure an assessment is currently loaded and your session has not expired. Then try the export action again from the assessment page.

My signup request is still pending

Admin approval is required before clinician access is enabled. Contact the admin support email if your request has been delayed.

Safe Use Guidance

These principles should always be followed when using CardioX in a clinical-style workflow.

1

Use outputs as support only

CardioX provides decision-support information and must never replace professional judgement or clinical responsibility.

2

Check data before submission

Incorrect patient values can affect predictions, interpretation, stored assessment history, and exported reports.

3

Interpret risk in context

Review the percentage, risk band, explainability, and advice alongside the patient’s wider history and clinical picture.

4

Escalate system issues early

If the system behaves unexpectedly or appears unstable, stop and contact support rather than relying on uncertain output.

5

Protect workflow integrity

Use the correct role-based area of the system and avoid using pages or actions not intended for your current permission level.

6

Remember the project scope

CardioX is an academic prototype and not a certified diagnostic or treatment tool for real-world deployment.

When to Escalate

The situations below should be escalated rather than worked around informally.

Repeated login or access failures

If users are repeatedly blocked from role-appropriate pages, contact support rather than repeatedly retrying credentials.

Missing or incorrect patient data

If patient details appear incorrect, pause the workflow and correct the record before creating or updating an assessment.

Export or report issues

If PDF generation fails or appears inconsistent, escalate the issue and avoid using partial or uncertain output.

Unexpected model behaviour

If the output appears clinically inconsistent or technically unstable, escalate to support and document the case clearly.
