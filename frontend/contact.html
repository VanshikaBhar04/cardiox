Frequently Asked Questions

Answers to common questions

Who is CardioX designed for?

CardioX is designed for healthcare professionals, clinician-facing teams, and cardiology-focused workflows that require structured cardiovascular risk review and interpretable decision support.

Does CardioX use real patient data?

No. The current implementation is based on a Cleveland-style heart disease dataset used for model development and system prototyping rather than live patient data.

Does CardioX provide a medical diagnosis?

No. CardioX is intended to support cardiovascular risk review and professional clinical decision-making. It does not replace diagnosis, treatment planning, or clinician judgement.

What machine learning model does CardioX use?

The current implementation uses a Random Forest model to generate a probability-based heart attack risk output from structured clinical attributes.

Where is application data stored?

The current platform uses SQLite as a lightweight persistence layer for application and assessment records within the present system architecture.

What should I do if the system is not working?

Check that the backend service is running, confirm that you are signed in with the correct role, and make sure all required form fields are completed before submitting a workflow action.
